# NFL Stats Chatbot

## About

This project is an NFL Stats chatbot created using BoodleBox. The chatbot is designed to help users find NFL statistics and information by asking questions in a conversational format.

## What the Chatbot Can Do

The chatbot can answer questions about NFL players, teams, games, and statistics. It is designed to search for accurate information and provide easy-to-understand answers.

## BoodleBox Chatbot

[Try the NFL Stats Chatbot here]((https://box.boodle.ai/a/@NFLStatBot))

## Example Questions

- What were Jared Goff's stats last week?
- How many receiving yards did Travis Kelce have?
- What was the Tennessee Titans' record last season?
- Who led the NFL in passing yards?
